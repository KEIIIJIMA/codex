## 1. 復習の間隔（指摘 0・1・3・7・12）

### 記録の形の変更点

```
prog[ID] = { c, x, s, t,   g: 段階 0〜5,  d: 次に出す日 'YYYY-MM-DD'（端末のローカル日付） }
```

- `g`・`d` は無くてもよい。**古い版の記録は書き換えず、読むたびに s と t から換算する**（`sched()`）:
  連続正解 s≥2（以前の「習得」）→ 段階3・最後に答えた日の7日後、s=1 → 段階1・翌日、s=0 → 段階0・翌日。
  答えたときに、その記録にだけ `g`・`d` が付く。`g`・`d` の形がおかしい記録も同じ換算にする（記録は捨てない）。
- 正解: 次に出す日が来ていれば段階を1つ上げ、`IV=[1,1,3,7,14,30]` 日後を次の日にする。初めての語の正解は段階1（翌日）。段階5のあとは30日ごと。
  **次に出す日が来る前の正解は、段階も日も変えない**（同じ日の連続正解も、差し戻しの正解も、1回ぶん）。誤答: 段階0・翌日。
- `s`（連続正解数）・`c`・`x`・`t` の意味は変えていない（古い版のページが新しい記録を読んでも、s≥2 を習得として扱える）。
- バックアップの取り込みは、`g`・`d` の形が正しければ残し、おかしければその2欄だけ落とす（記録は取り込む）。古い控え（`g`・`d` なし）もそのまま読める。
- 2つのタブ: 「回答数の多いほうを残す」処理は記録をまるごと選ぶので、`g`・`d` もその記録のものが残る（処理は変えていない）。
- 進行中のセッション（別のキー `tango-drill-v1-session`）に `pre`（始める前の状態。結果の「今回習得」を数えるため）を足した。`ids` には差し戻した語が2回以上入ることがある。`pre` の無い古い形も読める。
- 設定に `prefs.goal`（1日の目標。全教材で共通）、`prefs.trAfter`、`prefs.hideK`、教材ごとの `tmode`（「今日の学習」の形式）を足した。

### 動き

- 状態: 習得＝段階3以上。苦手＝誤答2回以上、または段階0で誤答の前に正解がある語（c > s）。単語帳の「苦手に登録」は誤答2回ぶん・翌日、「習得済みにする」は段階3・7日後。
- 出題: 既定の出題順（表示名は「復習→苦手→学習中→未学習」）は、どの出題範囲でも復習と新出を配分する。問題数の4割を新出に取っておき、復習が足りなければ新出で、新出が無ければ復習で、どちらも足りなければ期限前の習得の語で埋める。
  復習は期限の古い順。おまかせ＋ランダム／収録順も、同じ配分で先に確保してから並べ替える。
- 差し戻し: 誤答の3〜5問あと（残りが少なければ最後）に同じ語を差し込む。問題数の表示は差し込んだ後の数（1/10 → 2/11）、進み具合のバーは後ろへ戻らない。差し戻しの問題には「さっき間違えた語をもう一度」。
  結果の正答数は語ごとの最初の回答で数え（9 / 10 問）、出し直しの回数を添える。差し戻しの回答も1回の回答として記録・今日の回答数に入る。再読み込みのあとの再開は、差し込んだ後の並びのまま。
- ホーム最上部「今日の学習」: 期限が来た復習と新出だけの1セット（問題数は出題設定の問題数。「全部」のときは20）。形式は出題設定の「『今日の学習』の形式」（既定はフラッシュカード）。
  1日の目標（10〜100問。既定30）の達成度の線と「達成」。復習も新出も無ければ、ボタンの代わりに次の復習の日を出す。
- 結果: 「今回 習得n語・学習中n語（うち苦手n語）・習得のままn語」「次の復習 明日n語・3日後n語…」。単語帳の詳細に「次の復習: n日後（段階 g / 5）」。

## 追加の依頼: 意味・メモの編集

- 置き場所: フラッシュカードの裏面、4択・空所補充・読み入力・新しい形式の解答後の解説、単語帳の詳細、結果の誤答の解説に「意味・メモを編集」（44px）。その場に編集欄が開く。
  意味は1行に1つの textarea（元の意味が入っている。16px）、メモは自由記述。保存・キャンセル・元に戻す（確認あり）。保存後は「編集済み」の印と「元の意味を見る」。
  空にして保存、または元と同じ意味のまま保存すると、意味の編集は残さない。意味・メモ各2000字まで。全教材（関連語を含む）で使える。
- 保存: `tango-drill-v1` の `edits: { ID: { m:[…]（省略可）, n:"…"（省略可）, t } }`。消したときは `{ t, del:1 }` を残す。`edits` の無いデータ、形のおかしい `edits` でも動く（おかしい項目だけ使わない）。
  2つのタブは項目ごとに `t` の新しいほう。IDの移行（付け替え・null）を `edits` にも当てる（付け替え先が重なったら新しいほう）。バックアップの書き出し・取り込みに含める（古い控えも読める。おかしい編集は件数を知らせて読み飛ばす。全部消したあとでも控えから戻せる）。
  「記録のリセット」では消さない。データ管理に「編集した意味・メモをすべて消す」（件数つき・確認あり・全教材）。
- 表示: 利用者の文字は必ず `esc()` を通す（`<script>`・`<img onerror>`・閉じタグを入れても実行されず、そのまま文字で出ることをテスト）。
  出題（4択の選択肢・正誤の判定・意味→語の設問・空所補充）は元の意味のまま。裏面・解説・単語帳・結果・苦手ワードには利用者の意味。単語帳の検索は利用者の意味・メモにも当たる。
  意味を編集した語は、意味ごとの用例を意味の下にまとめて出す（用例は元の意味に対応するものなので）。
- 保存できなかったときは、編集欄を開いたまま欄の中に知らせ、既存の「保存できません」の知らせも出す。編集欄を開いている間は、回答のキー操作（1〜4・Enter・←→）を受け付けない。
- 迷った点: (a) 古い版のページ（この機能の無い版）を別のタブで開いたまま保存されると、そのタブは `edits` を知らないので保存データから `edits` が落ちる（新しい版のタブが開いていれば、次の保存で書き戻す）。
  仕様どおり同じキーに入れたが、別のキーに分ければ起きない。(b) バックアップの取り込みでは、控えの「消した印」は取り込まない（控えを戻して手元の編集が消えるのを避けた）。
  (c) 「読み」の教材は意味＝読みなので、編集すると裏面の読みの表示が変わる（判定は元の読みのまま）。(d) テストは実装と同時に書いた（先に失敗を確かめる手順は踏んでいない）。

- **成立順**: 作品ごとに時期の幅を作る。成立年のデータ（`book/seiritsu.json` 由来の `sei`）があれば、確実性「高」はその年、「中」や「ごろ」は前後10年、「低」（徒然草・浮世物語・花月草紙）は使わない。無ければ説明の世紀（その100年間）。
  並べさせるのは、幅どうしが25年以上離れた作品だけ（同じ世紀の作品どうし、年のはっきりしない作品どうしは並ばない）。その作品＋時期の離れた3作品。
  まとめの4項目（鏡物・八代集・三大随筆・日記の成立順）は、本の順から4つまでを順を保って出す。
  画面: 作品を押した順に番号が付く（もう一度押すと外れる）、「やり直す」、全部押すと「答え合わせ」（下端の操作欄）。解答後は正しい順に並べ直し、年・世紀と自分の順を出す。キー操作は数字と Enter。
- 回答はもとの項目のIDに記録するので、同じ語を別の形式で同じ日に正解しても、段階が上がるのは1回。「今日の学習」の形式にも選べる。
- 指摘13の「和訳は解答後」: 出題設定（英語の教材だけ）に「空所補充の和訳」。既定は今までどおり「解答前から出す」。

## 判断に迷った点

1. **期限前の正解は段階を上げない。** 依頼は「同じ日の連続正解は1回と数える」。それより厳しく、次に出す日が来る前の正解（3日後の予定の語を翌日に正解、など）も上げない。
   毎日「すべて・ランダム」で回す人は、期限の来ていない語では進まない。日が違えば上げる決まりに緩めるなら、`record()` の条件1か所。
2. **古い「習得」（s≥2）は段階3・最後に答えた日の7日後に換算。** 表示は習得のままだが、7日以上前に答えた習得語は全部いっぺんに復習待ちになる（1セットに出るのは問題数の6割まで。「復習待ち n語」と出る）。
3. **苦手の決め方。** 正解したあとで落とした語は、日をあけて正解する（段階1になる）と学習中に戻る。誤答2回以上の語は習得するまで苦手のまま。単語帳の「苦手に登録」は誤答を2回ぶんにする（誤答数が増える）。
4. **差し戻しの細部。** セットの最後の問題を間違えると、すぐ次に同じ語が出る。結果の正答率は最初の回答で数える。
5. **「今日の学習」の新出の数。** 復習が少ない日は、問題数まで新出で埋める（初めての利用者は「復習0語＋新出20語」）。1日の新出の上限は設けていない（押すたびに次のセットが出る）。1日の目標の既定は30問・全教材で共通。
6. **解答前に漢字・分野を隠す設定（指摘6）の既定は「出す」。** 修正案は「解答前は仮名だけ」が既定だが、表面の漢字を前提にした利用（とテスト）を変えないよう、切り替えだけ足した。既定を「隠す」にするなら `hideK()` の1か所。
7. **用例の意味は、同じ語のほかの意味を誤答にしていない**（上の抜き取り確認）。指摘の修正案（同じ語の他の意味＋他の語の意味）より弱いが、誤答で段階0に戻る仕組みなので、答えが複数ある問題を避けた。
   意味の3つ目以降も、その用例つきで出題される点は満たしている。
8. **語法の誤答から外す前置詞の表（`PREP_ALT`）は、私の知識で書いた。** conform to/with、culminate in/with、conversant with/in、on/to the contrary など、同じ意味で言い換えられる前置詞を誤答にしないための除外だけで、問題や正答は足していない。不要なら表を空にできる。
9. **敬語の種類は3択だが、丁寧語が正答の語が無い。** 丁寧語を含む語（はべり・さぶらふ・まかる・まかづ）は種類が2つあるので対象外。
10. **古い版のページを開いたままのタブ。** 古い版は `g`・`d` を知らないので、そのタブで答えた記録は `g`・`d` が前のまま残る（予定が少しずれるだけで、記録は壊れない）。`edits` は上の「追加の依頼」(a)。
11. **新しい形式の記録先。** もとの項目のIDに記録するので、「意味は覚えたが接続は覚えていない」は区別されない。分けるなら接頭辞つきのID（例 `gs:`）を足す形になり、基準の更新が要る。
12. 見送り: 識別問題（指摘4のL）、敬意の方向・元の動詞（指摘9）、語法のデータ追加（指摘13のL）、番号順の習得状況の一覧（指摘5のM）、出題設定の折りたたみ（指摘12）、誤答の多い語の習得条件の加重（指摘7）。
