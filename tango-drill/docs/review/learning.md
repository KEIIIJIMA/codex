0. [medium/design] 習得が「2回連続正解」で確定し、日をあけた再確認がない
   場所: tango-drill/src/index.tmpl.html:323-324 status()/record()、351-352 order()
   根拠: status() は連続正解数 s≥2 だけで習得と判定し、解答日時 t を使わない。実機で「まだ」にした3語が、直後の再挑戦と次のセットで続けて「覚えた」を押すと数分のうちに習得になった（記録 c:2,x:1,s:2）。習得語は並び順の最後に回り、復習の機会がない。
   修正案: 記録に段階と次回日を足し、正解で1→3→7→14→30日後に再出題、誤答で1日後に戻す。同じ日の連続正解は1回と数え、習得は3段階目以降にする。忘れかけた頃に思い出す回数が増え、入試日まで残る。実装M（既存記録は s と t から換算できる）。
   出どころ: app-learning

3. [medium/design] 間違えた語が同じセットの中で再出題されない
   場所: tango-drill/src/index.tmpl.html:373 next()、534-540 viewResult()
   根拠: next() は次の語へ進むだけで、誤答語は結果画面の「間違えた語をもう一度」を押すまで出ない。結果画面は正答率・誤答一覧・再挑戦ボタンだけで、今回習得した語数や次に復習する時期は出ない（実機で確認）。
   修正案: 誤答語を3〜5問後に同じセットへ差し戻し、正解するまで1〜2回繰り返す。結果には「今回習得n語・学習中n語」を出す。正答を見た直後に思い出し直すので、初見の語が定着しやすい。実装S。
   出どころ: app-learning
