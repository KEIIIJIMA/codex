# 難関大 単語ドリル

大学受験（難関国公立〜準難関私大レベル）向けの古文単語・英単語学習アプリ。
依存ライブラリなしの単一 HTML ファイルで、`index.html` をブラウザで開くだけで動きます。

## 収録内容

| 科目 | 語数 | 内容 |
| --- | --- | --- |
| 古文単語 | 226 | 見出し・漢字表記・品詞・意味（多義）・用例と訳・古今異義などの注・必修/発展レベル・分野タグ |
| 英単語 | 268 | 単語・品詞・意味・例文と訳・派生語/関連語・必修/発展レベル・分野タグ |

## 機能

- フラッシュカード（自己判定）、4択テスト（語→意味 / 意味→語）
- 出題範囲（おまかせ・未習得のみ・苦手のみ・レベル別・分野別）、問題数、出題順の設定
- 正誤に応じた「未学習 / 学習中 / 苦手 / 習得」の自動判定と、苦手だけの復習
- 単語帳（検索・絞り込み・手動で苦手/習得の登録）
- 成績（習得率、直近14日の回答数、苦手ワード一覧）
- 学習記録のバックアップ（コピー＆貼り付けで別端末へ引き継ぎ）
- キーボード操作、ダークモード、スマホ幅対応

学習記録はブラウザの `localStorage` に保存され、端末ごとに独立しています。

## ファイル構成

```
tango-drill/
  index.html            # ビルド済み・単体で開ける完全版（これを配布する）
  dist/artifact.html    # claude.ai Artifact 用（外枠の html/head/body なし）
  src/index.tmpl.html   # アプリ本体（HTML/CSS/JS）のテンプレート
  src/data_kobun.js     # 古文単語データ
  src/data_eigo.js      # 英単語データ
  build.js              # src/ から index.html と dist/ を生成
```

## 単語の追加・修正

`src/data_kobun.js` / `src/data_eigo.js` の配列に行を足し、`node build.js` を実行してください。
各行の形式はファイル先頭のコメントに記載しています。
